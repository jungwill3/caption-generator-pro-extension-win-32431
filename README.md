## About Caption Generator Pro

Caption Generator Pro is an Adobe extension designed to streamline subtitle and caption creation for video projects. It uses AI transcription through OpenAI Whisper to help turn spoken content into editable text for use within Adobe Premiere Pro and After Effects.

The extension is intended for editors, motion designers, and video production teams working with dialogue-heavy footage. By bringing subtitle and caption generation into familiar Adobe workflows, it provides a focused way to prepare text-based video elements without leaving the creative tools used for editing and compositing.
